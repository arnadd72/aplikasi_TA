# Padi Scan 2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mengubah aplikasi menjadi Padi Scan 2.0: identifikasi offline yang dapat diaudit, navigasi lapangan, riwayat terstruktur, petak/musim/survei, dan UI “Catatan Lapangan”.

**Architecture:** Pertahankan Flutter + SQLite + TFLite lokal. Pisahkan domain murni, penyimpanan SQLite, alur identifikasi, dan layar; migrasi basis data memakai pola expand-only v1→v2 agar data lama tetap terbaca. Shell empat tujuan menjadi pintu utama, sedangkan kamera, pratinjau, hasil, dan survei memakai alur terfokus.

**Tech Stack:** Flutter/Dart, Material 3, sqflite, image_picker, image, tflite_flutter, share_plus.

**Spec:** `docs/PRD-PADI-SCAN-2.0.md`; tampilan: `docs/UI-REDESIGN-PADI-SCAN-2.0.md`.

## Global Constraints

- Seluruh identifikasi dan data inti berjalan offline (NF-01).
- Rekomendasi hanya bahan aktif; tanpa merek dagang dan dosis (NF-05).
- Minimum Android 8.0/API 26; UI Bahasa Indonesia.
- Target inferensi model <1 detik; preprocessing dan end-to-end dicatat terpisah.
- Ambang keyakinan 70%; R1–R5; label model asing adalah galat kontrak, bukan R3.
- Algoritma dan dataset penelitian tidak diubah; penyimpangan ditandai `[ASUMSI]`.
- Tidak menambah layanan cloud, akun, GPS, notifikasi, diagnosis di luar empat kelas, atau fitur roadmap A22–A24.
- Gunakan Plus Jakarta Sans lokal, Soft Sage, target sentuh ≥48dp, Semantics, responsif tanpa overflow.

## Review Focus

- Basis data v1 berisi riwayat lama lalu dibuka v2: baris lama tetap tampil dengan default aman.
- Label keluaran model tidak dikenal: alur berhenti sebagai galat teknis dan tidak memberi rekomendasi salah.
- Foto gelap/buram: pengguna mendapat peringatan deterministik dan masih dapat memilih foto ulang.
- Petak/musim dihapus atau tidak aktif saat riwayat lama merujuknya: timeline tetap dapat dibuka.
- Layar 320dp, teks besar, mode gelap: navigasi dan tindakan utama tidak terpotong.
